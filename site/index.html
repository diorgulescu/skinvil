Craft 3D Voxel Skins & Forge Ready-to-Play .mcpack Packs

Skinvil is a fast, native desktop studio built with Tauri v2 (Rust), TypeScript, and Three.js. Paint directly on animated 3D characters, toggle armor layers, manage a local Wardrobe, and export multi-skin Minecraft Bedrock .mcpack archives or Java .png textures — completely offline, with zero accounts, zero ads, and zero network calls.

Inside the Studio

Three Views of the Skinvil Workflow

Click any screenshot to inspect it at full desktop resolution.

01 • 3D + 2D Studio

Zero-Mode-Switching 3D Viewport & Synced 64×64 UV Grid

Paint directly onto the 3D voxel model or refine individual texels on the synced 2D UV map — every stroke updates a single 64×64 RGBA canvas with 50-step Undo/Redo.

  • Effortless Desktop Mouse Controls: Left-click on the character paints immediately; dragging empty space or right-dragging anywhere orbits the camera.
  • 12-Part Interactive Mini-Mannequin: Hide or solo any of the 6 Base parts or 6 Outer armor pieces to paint inner limb surfaces cleanly.
  • Color Workshop & Kid Palettes: Smooth HSV picker, 12 recent swatches, and 4 curated palettes (Skin Tones, Knights, Hoodies, Nature).
02 • Wardrobe & .mcpack

Local Character Wardrobe & 1-Click Bedrock .mcpack Forge

Save all your creations locally with auto-rendered 2D portraits, mix Classic (Steve 4px) and Slim (Alex 3px) geometries, and bundle multiple characters into one ready-to-install skin pack.

  • Bedrock .mcpack Packager: Rust generates compliant ZIP-root manifest.json, skins.json, UUIDv4 headers, and texts/en_US.lang files in milliseconds.
  • Java Edition .PNG Export: Export clean individual .png skin files ready for Minecraft Launcher.
  • 6 Offline Templates & Smart Import: Auto-converts legacy 64×32 skins to 64×64 and preserves 128×128 HD textures.
03 • Poses & Bilingual UI

Animated Poses, 3D Outer Armor Layer & Bilingual RO / EN UI

Collapse the 2D panel for a wide 3D stage, paint 3D helmets, visors, sleeves, and jackets on the Outer layer, and preview your character in motion.

  • Kid-Friendly Auto-Freeze: Stand, Walk, and Action poses animate smoothly in real time and automatically freeze mid-stroke the instant you paint on a limb.
  • Crisp Per-Face UV Shader: Custom GLSL clamping eliminates MSAA neighbor-texel bleed on transparent 3D Outer layers.
  • Instant RO | EN Switch: Built for children ages 6–12 with complete Romanian and English localization and an offline GPLv3 viewer.

Build & Verify from Source

Requires Node.js 22.12+ and Rust stable (1.77.2+). Clone the repository, run the automated frontend and Rust test suites, and compile your own native installer: 

git clone https://github.com/diorgulescu/skinvil.git
cd skinvil
npm install
npm test && cargo test --manifest-path src-tauri/Cargo.toml
npm run tauri build
